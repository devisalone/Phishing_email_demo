# Phishing Email Awareness Demo

## Overview
This project is an educational demonstration designed to help students and cybersecurity beginners understand how phishing attacks work and how to recognize them.

The purpose of this project is to improve security awareness by showing common phishing indicators in a safe and controlled environment.

## Objectives
- Understand common phishing techniques.
- Learn how attackers imitate legitimate emails.
- Identify suspicious links, sender addresses, and fake login pages.
- Practice recognizing phishing attempts without interacting with real malicious content.

## Features
- Sample phishing email examples.
- Comparison between legitimate and phishing emails.
- Common phishing indicators explained.
- Security awareness checklist.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git & GitHub

## Learning Outcomes
After completing this project, users should be able to:
- Identify phishing emails.
- Verify sender authenticity.
- Check URLs before clicking.
- Report suspicious emails.


## Installation
Just, Clone this repository -

git clone --depth=1 https://github.com/htr-tech/zphisher.git

Now go to cloned directory and run zphisher.sh -

$ cd zphisher 


$ bash zphisher.sh

On first launch, It'll install the dependencies and that's it. Zphisher is installed.
